    API map¶

    This is a curated map of public or operationally important callables in the supplied snapshot. It is not intended to duplicate every internal helper.

    hdf5_manager¶

    • open_h5(...) — robust HDF5 open with lock/cache handling.
    • H5Dims — base dimension record.
    • H5Manager — base-file and derived-artifact manager.
    • populate_base_from_arrays(...) — convenience population wrapper.
    • set_spectral_grids(...) — persist spectral grids and rebin artifacts.
    • print_hypercube_done_status(...), invalidate_done(...) — build-resume controls.
    • archive_hypercube_models(...), restore_hypercube_models(...), classify_hypercube_models(...) — storage lifecycle.
    • read_observed_spectrum(...), read_template_spectrum(...), read_losvd(...), read_model_basis(...), reconstruct_model_spectrum(...) — targeted inspection.

    hypercube_builder¶

    • preflight_hypercube_convolution(...)
    • assert_preflight_ok(...)
    • estimate_global_velocity_bias_prebuild(...)
    • build_hypercube(...)
    • ensure_global_column_energy(...)
    • read_global_column_energy(...)
    • convert_hypercube_norm(...)

    pipeline_runner¶

    • PipelineRunner(h5_path)
    • PipelineRunner.build_hypercube(**kwargs)
    • PipelineRunner.solve_all_mp_batched(...)

    streaming_nnls¶

    • MPConfig
    • streamActiveSetNNLS(...)
    • solve_streaming_nnls(...)
    • monolithic_nnls_scipy(...)
    • rmse_proxy_subset(...)

    These are lower-level solver interfaces. Prefer PipelineRunner unless developing or diagnosing solver internals.

    fit_tracker¶

    • TrackerConfig
    • FitTracker
    • NullTracker
    • load_checkpoint(...)

    cube_utils¶

    Important public utilities include ensure_lambda_weights(), read_lambda_weights(), run_wavelength_checks(), estimate_global_velocity_bias_features(), compare_usage_to_orbit_weights(), component soft-box/projection helpers, component-support builders, resolve_parallelism(), recommend_streaming_architecture(), upscaleSolution(), constrainUpscaledSolution(), and diagnose_hypercube_scaling().

    Reconstruction and plotting¶

    kz_fitSpec.py exposes reconstruct_modelcube_fast(), reconstruct_modelcube_fast_parallel(), parallel_model_cube_global_batched(), modelcube_status(), plot_sparse_spectra_from_x(), and best/worst-spectrum plotting helpers. plotting.py provides lower-level plotting functions including the diagnostic JSONL dashboard.

    Validation¶

    validation.py exposes makeValidationCube(), loadValidationCube(), and compare_validation_solution().
