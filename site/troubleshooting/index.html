    Troubleshooting and known issues¶

    Runner / streaming-solver signature mismatch¶

    In the supplied snapshot, PipelineRunner.solve_all_mp_batched() calls:

    solve_streaming_nnls(
    ...,
    regularisation_scale=regularisation_scale,
)

    but streaming_nnls.py::solve_streaming_nnls() does not declare a regularisation_scale keyword. Calling this exact path will therefore raise a TypeError unless the runtime module differs from the packed source or the mismatch is patched. streaming_nnls_constrained.py contains a solver variant whose solve_streaming_nnls() does accept regularisation_scale, suggesting an incomplete integration between solver variants.

    Before production runs, make the import/call contract consistent and add a smoke test that instantiates PipelineRunner and executes a tiny solve.

    Documentation/source drift¶

    The old docs/CubeFit.md describes a Kaczmarz solver with trust regions, backtracking, and tile-local weighted NNLS polish. The current primary runner imports a streaming NNLS implementation instead. Do not use the old solver tuning tables as authoritative for the current solver without verifying the variable is read by the selected implementation.

    /X_global shape drift¶

    Older documentation describes /X_global as flattened (C*P,). The current runner writes the solver result as (C, P) and stamps layout='C_P'. Some helper functions still flatten inputs internally. When interoperating with older files, inspect dataset dimensionality and reshape explicitly using known (C, P) metadata.

    Environment specification drift¶

    README.md names dependencies such as SciPy, h5py, threadpoolctl, and optional Cython, while environment.yml in the snapshot lists only Python, NumPy, Matplotlib, Zarr, numcodecs, and tqdm. The environment file therefore does not appear sufficient to reproduce all imports exercised by the current codebase. Consolidate dependencies into one authoritative environment specification.

    MkDocs navigation¶

    The existing mkdocs.yml references docs/index.md, but the packed directory listing contains only docs/CubeFit.md, docs/CubeFit.html, and docs/CubeFit.pdf. This overhaul supplies docs/index.md and a complete multi-page navigation replacement.

    HyperCube incomplete¶

    Use print_hypercube_done_status() to inspect the _done bitmap. If a tile must be regenerated deliberately, use invalidate_done() rather than deleting arbitrary HDF5 slices. Confirm HyperCube.attrs['complete'] before fitting.

    Model/data wavelength mismatch¶

    The streaming solver explicitly checks that /HyperCube/models.shape[-1] matches /DataCube.shape[1]. Rebuild or correct the rebinning/grid setup rather than bypassing this check.

    Multiprocessing is slower than expected¶

    Check process count × BLAS threads against allocated CPUs. On SLURM, compare settings with SLURM_CPUS_PER_TASK. Use resolve_parallelism() or recommend_streaming_architecture() as starting points, and avoid nested oversubscription.
