CubeFit Solver Maintenance Handbook
===================================

Canonical editable source:
  CubeFit_Solver_Maintenance_Handbook.tex

Local compilation (recommended):
  latexmk -pdf CubeFit_Solver_Maintenance_Handbook.tex

or:
  pdflatex CubeFit_Solver_Maintenance_Handbook.tex
  pdflatex CubeFit_Solver_Maintenance_Handbook.tex

The supplied PDF was generated from the same handbook content using ReportLab
because the current execution environment does not contain a TeX engine.

Maintenance convention:
  - Update the snapshot date on the title/header.
  - Prefer function names and mathematical contracts over line numbers.
  - Add an entry using Appendix C after solver changes.
